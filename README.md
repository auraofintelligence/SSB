Sovereign Space Builder (SSB) is a static interactive explorer for a broad regenerative systems
concept spanning system architecture, game design, robotics, the Fractal Ark, trust, security,
ethics and an implementation pathway.

The site makes a large specification easier to explore. It is a concept and planning interface,
not evidence that the proposed infrastructure, robotics or governance systems have been built or
approved.

## What is here

- `index.html` is the interactive system explorer.
- `Sovereign Space Builder_ Full System Specification.pdf` is the source specification bundled
  with the project.
- `assets/` contains the local visual and interface assets.
- `LICENSE` records the reuse conditions.

## Use locally

Open `index.html` in a browser. The current version is static and has no backend or account system.

Treat feasibility, safety, engineering, cultural authority, land access, finance and regulatory
approval as separate work still requiring current evidence and qualified human review.
